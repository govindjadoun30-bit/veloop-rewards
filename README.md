# VELOOP Rewards 🚀

VELOOP Rewards is a modern gamified rewards web app prototype where users can complete activities, earn XP, unlock new levels, collect rewards, and track their progress.

The project is built using simple front-end technologies and is designed as a responsive mobile-first rewards experience.

---

## ✨ Features

### 🎮 Gamified Level System

VELOOP includes a 10-level progression system:

| Level | Rank | Required XP |
|------:|------|------------:|
| 00 | Newcomer | 0 XP |
| 01 | Starter | 500 XP |
| 02 | Bronze | 1,200 XP |
| 03 | Silver | 2,200 XP |
| 04 | Gold | 3,500 XP |
| 05 | Platinum | 5,000 XP |
| 06 | Diamond | 7,000 XP |
| 07 | Emerald | 9,500 XP |
| 08 | Sapphire | 12,500 XP |
| 09 | Master | 16,000 XP |
| 10 | Legend | 20,000 XP |

Users earn XP by completing activities and playing the mini-game.

---

## 🏆 Level Progression

The app tracks:

- Current XP
- Current Level
- XP required for the next level
- XP progress bar
- Current rank
- Completed tasks
- Daily streak
- Rewards earned

When the user reaches a new level, the app displays a level-up notification.

---

## ⚡ XP Catcher Mini Game

VELOOP includes an interactive mini-game called **XP Catcher**.

### Game Features

- 20-second game timer
- XP orbs
- VE reward orbs
- Gem orbs
- Random orb spawning
- Score tracking
- XP collection
- VE collection
- Gem collection
- Game completion screen

Players can click/catch the moving reward objects before the timer ends.
