VELOOP Rewards ⚡

A premium dark-themed Rewards & Gamification Web App designed to demonstrate how users can earn XP, collect VEs and Gems, complete activities, play mini-games, and progress through multiple levels.

The interface is inspired by modern mobile gaming and rewards applications, with a dark black background, gold premium accents, glowing reward graphics, level badges, animated pop-ups, and mobile-first responsive design.

⚙️ How It Works

1. Start at Level 00

The user begins as:

Newcomer — Level 00

2. Complete Activities

Users complete available activities to earn XP and VEs.

3. Gain XP

XP is added to the user's progression.

4. Level Up

Once the required XP is reached, the application automatically updates the user's level.

5. Receive Rewards

Level-up rewards include:

- VEs
- Gems
- New level access
- Additional reward opportunities

6. Play XP Catcher

Users can also earn XP and rewards through the mini-game.

🎯 Project Objective

The objective of VELOOP Rewards is to create a simple but engaging GPT/rewards-platform experience where users can clearly understand:

- What they can earn
- How much XP they receive
- Their current progress
- What they need for the next level
- What rewards they have collected
- How they can continue earning

The design focuses on clarity + gamification + reward visibility.
